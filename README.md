是的，这里只是一个置物架，用来存放各种我自己做的一些小玩意。每个项目都在 **GitHub** 与 **Gitee** 同步维护，下表「链接」一列分别指向 **GitHub 主仓库** 与 **Gitee 镜像**。本店仓库的 Gitee 镜像在 [gitee.com/ji-or-ji/ji-or-ji-shop](https://gitee.com/ji-or-ji/ji-or-ji-shop)。

## 使用说明

很简单，只需要点击 **相应的链接** 就可以跳转到 **相应的界面** 了。
